# CarHome — лёгкий лаунчер для магнитолы

1. Открой папку в Android Studio (File → Open), дождись синхронизации Gradle.
2. Build → Build App Bundle(s) / APK(s) → Build APK(s).
   Готовый файл: app/build/outputs/apk/debug/app-debug.apk
3. Скинь APK на флешку и установи, или: adb install app-debug.apk
4. Нажми «Домой» → выбери CarHome → «Всегда».
5. Нажми на карточке «Разрешить доступ к музыке» и включи CarHome в списке —
   после этого появятся трек, обложка и кнопки управления.
